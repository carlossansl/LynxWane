## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/LynxWane.git`
2. `cd LynxWane`
3. Install in editable mode: `pip install -e .`

## Configuration

LynxWane is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
